All published versions will be marked with proper syntax, explained here. A "zero release" is a version that is NOT intended for public testing, because it explicitly doesn't work properly, and is only there to have an official "version" out. These will be marked as v1.X.x-alpha.X. Again, these versions are intentionally not functional, and are not intended to be tested by others. 

Beta versions are the pre-release versions explicitly intended to be tested by others. These will be marked as v1.X.x-beta.X.

Official full releases will not have any special markings, named simply v1.X.x.
